1. 改 `index.html` 或重產 PDF（改履歷後跑 `make_public_resume.py` 再 html-to-pdf）。
2. `python -I _build/check_site.py` 與 `shots.py` 皆過。
3. `git commit` 後兩邊都推：`git -C E:/北醫附醫/建名/個人網頁 push origin main` 與 `... push babymlin main`（專案 settings.local.json 已允許此資料夾的 git push，其他寫法會被權限守門擋）。
